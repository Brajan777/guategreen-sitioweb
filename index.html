📋 Ver Código SQL para configurar tu Supabase en 1 clic

Copia este código y pégalo en el SQL Editor de tu proyecto en Supabase. Creará las tablas automáticamente con permisos de lectura y escritura para tu tienda:

-- 1. Tabla de Productos del Catálogo
create table if not exists public.gg_products (
  id bigint primary key,
  cat text,
  name text,
  latin text,
  price numeric,
  old_price numeric,
  rarity text,
  panel text default 'sage',
  stock_qty int default 0,
  stock text,
  order_num int default 999,
  description text,
  images jsonb,
  deleted boolean default false,
  updated_at timestamp with time zone default now()
);

-- 2. Tabla de Portada (Hero) y Configuración
create table if not exists public.gg_hero (
  id text primary key,
  data jsonb,
  updated_at timestamp with time zone default now()
);

-- 3. Desactivar RLS para permitir lectura y guardado inmediato sin bloqueos
alter table public.gg_products disable row level security;
alter table public.gg_hero disable row level security;

grant all on table public.gg_products to anon, authenticated, service_role;
grant all on table public.gg_hero to anon, authenticated, service_role;

Preguntas Frecuentes

Respuestas a las consultas más comunes sobre empaque, envíos y aclimatación de tus especímenes.

¿Dónde comprar plantas exóticas en Guatemala?
En Guategreen encuentras la mayor selección de plantas exóticas y de colección en Guatemala (Monsteras variegadas, Philodendrons raros, Alocasias y Anthuriums) con origen certificado y entregas a domicilio en Ciudad de Guatemala y envíos a todos los departamentos.
¿Hacen envíos de plantas exóticas a toda Guatemala y cuáles son los tiempos?
Sí, realizamos envíos seguros con empaque botánico especial a todos los departamentos de Guatemala. En la Ciudad de Guatemala entregamos en 24 a 48 horas, y para el resto del país de 2 a 3 días hábiles.
¿Qué métodos de pago aceptan para comprar plantas?
Aceptamos transferencia bancaria en Quetzales (GTQ), pago con tarjeta de crédito/débito y opción de pago contra entrega en zonas seleccionadas de la Ciudad de Guatemala.
¿Las plantas exóticas vienen aclimatadas al clima de Guatemala?
¡Totalmente! Todos nuestros especímenes pasan por un riguroso proceso de aclimatación de varias semanas en nuestro vivero local en Guatemala antes de estar disponibles en el catálogo, asegurando que prosperen sin problemas en tu hogar.
¿Recibiré asesoría o ficha de cuidado botánico con mi compra?
Sí. Cada planta incluye su guía de cuidados personalizada con recomendaciones exactas de luz, riego y sustrato. Además, cuentas con asesoría continua por WhatsApp con coleccionistas expertos.
